## B.2 Attribute value types

One symbol, written before each attribute (`b`/0 ends the list).

| Id | Symbol | Type | Encoding | Emitted by the writer? |
|---|---|---|---|---|
| 1 | `c` | `Float` | Float (5 chars) | yes — any number that is non-integer **or negative** |
| 2 | `d` | `Int` | Int (4) | no (reader only) |
| 3 | `f` | `String` | ShortInt index into the string map (2) | yes |
| 4 | `g` | `Bool` | `b`/`c` (1) | yes |
| 5 | `h` | `Color3` | ShortInt index into the colour map (2) | yes |
| 6 | `j` | `Vector3` | 3 × Float (15) | yes |
| 7 | `k` | `LongInt` | LongInt (6) | yes — any non-negative integer |
| 8 | `m` | `SignedInt` | SignedInt (3) | no (reader only) |
| 9 | `p` | `CFrame` | CFrame (24) | yes |

Attribute values of any other Roblox type (`UDim2`, `Vector2`, `Rect`, …) are ignored by the exporter. Attribute names beginning `RBX_` are skipped.

## B.5 The 72-symbol alphabet

Index → symbol, 0-based. All multi-symbol integers are big-endian base-72 over this alphabet.

```
bcdfghjkmpqrtvwxy346789!"#$%&'()*+,-./:;<=>?@BCDFGHJKMPQRTVWXY[\]^_`{|}~
```

| Width | Max value (72^n − 1) | Used for |
|---|---|---|
| 1 | 71 | type ids, property ids, enums |
| 2 | 5,183 | ShortInt, map indices, ShortBoundedFloat |
| 3 | 373,247 | SignedInt, BoundedFloat |
| 4 | 26,873,855 | Int (string lengths) |
| 5 | 1,934,917,631 | — |
| 6 | 139,314,069,503 | LongInt |

Characters `"`, `'`, `\`, `` ` `` and `&` appear in the alphabet. The alphabet omits lowercase `a e i l n o s u z`, digits `0 1 2 5`, and uppercase `A E I L N O S U Z` (the reason is not stated in the source; likely to avoid look-alike characters and accidental words — *inference*).
