## M8c part 3 (ALERT) is DONE (docs v0.21, suite = 1398 passing)
`src/alert.luau` -> `BreachAlert.luau` (76 tests in tests/alert_tests.luau, hooked into tests/run.luau; docs section 8.3.1). What it does: monotonic level 0..3 via `raise(amount, reason, min, max)` / `lockdown()`, publishes `Mission_AlertLevel` / `Mission_AlarmRaised` through logic:set; `AlertRaiseCondition` on the rising edge (components outside StateComponents/ ignored, so the Diplomat's `Disabled/` one is inert); consumes Trespass events: MAJOR = witness flees to its farthest own-route node, radios after RadioSeconds, then lockdown (cancelled if it dies/is incapacitated/despawns); MINOR = approach, ask, `alert:answer(bot, player, success)`, fail/timeout = major, `MinorRaisesAlert` option (King Street +1 vs Bathurst none); disguise-piercing profiles (default LeadSecurity); anomaly registry `addAnomaly(Body|Radio|BrokenGlass|BrokenCamera)`, bodies auto-registered from bots:setFlag Dead/Incapacitated, found only by a bot that SEES the point (new `Sight:canSeePoint`), comment (BotSay) then radio "10-66 at (cell)". New Bots API: `command(id, state, x,y,z)`, `hold`, `resume`, event `BotReached`; commanded bots are skipped by the patrol logic. Event field names: AnomalyFound/AnomalyReported use `Anomaly` (NOT `Kind`, which is the event kind).
Alert numbers are all [P] defaults in `Alert.Defaults` (AlarmRaisedAt = 3, RadioSeconds 4, CommentSeconds 1.5, QuestionSeconds 8, SilenceSeconds 60, MinorRaisesAlert false, FailedAnswerIsMajor true).

## Owner answers folded in (alert revised)
States Calm/Normal/Alert/Lockdown = levels 0..3; Fighting is a deprecated flag (guards attack without lockdown). Hiding spot priorities: (1) far but close enough to run back and ask, else don't hide; (2) easy there-and-back; (3) cover line of fire if a weapon was seen. King Street vs Bathurst is NOT per mission (probably a tag on the guard; name unknown: `params.MinorRaiseTags`). Failed question = major trespass but the guard escorts you out, and re-entering that place = lockdown if seen (his idea). "I'm leaving" = leave yourself or get escorted (his idea). Event fields: `Anomaly` not `Kind`.

## Resolved by scanning the real maps
`Mission_AlarmRaised` = lockdown (level 3), latched; evidence in docs 8.3.1. The level is NOT monotonic: the maps write/lower `Mission_AlertLevel` (scripts, ReduceAlertLevel/ResetAlertLevel bluffs, StandardRadioAlertReduction); BreachAlert now follows those writes (event AlertLowered, Reason MapWrite). Decay is now built: AlertLowerCondition (rising edge -> level := AlertLevel expr, only lowers) and StandardRadioAlertReduction (Diplomat only; calm spell lowers 2->1->0, difficulty-gated, off while AlertReductionDisabled; times 60 s are guesses). Not built: the Project's `Unalarm` (alarm un-latch?).

## Props and doors (adapter v0.2, wrapper/BreachRoblox, 58 offline tests)
A mission has no prop or door geometry, only placeholders: one Part per prop in the `Props` folder, Name = the prop's name in the prop library (`Templates/Props.rbxm` of MoonstoneSkies/InfiltrationEngine-Custom-Missions, 378 models), CFrame and Size where, Attributes the configuration. A library model has a `Base` part whose Size equals the placeholder Size [O: SlidingBlastDoor 10.4 x 7.4 x 0.9, DoorWood Base 5 x 7 x 1]; `Core.propPlacements(mission, hasModel)` returns the placements (pure Luau, tested), `RobloxHost:renderProps` clones each model and puts its Base on the placeholder. `DoubleDoor = true` (placeholder 10 wide) = two 5-wide leaves at +-size.X/4, the second turned 180 degrees [P, check in Studio]. `AltPropModel` is ignored for now. Doors are drawn closed and do not open yet.
Blacksite numbers: 1,861 placeholders of 151 kinds; the library covers 106 kinds = 834 placeholders (81 door models, 11 of them double). The rest: ShuffleTarget 529, PartCollection 103, ItemSpawn 38, PathfindingBlocker 30, GuardCombatNode 24, triggers and covers (logic markers, correctly not drawn), plus DecorativePipe 51, DecorativeVent 30, Window 27, CardboardBox 23 and others that are not in the community library (probably game-only assets).
Setup in Studio (once): drag `Props.rbxm` into Studio and move its `Assets` folder under ReplicatedStorage (the same setup the Prop Preview plugin asks for). Without it the adapter prints a hint and draws no props. **Not run in Roblox yet.** Props.rbxm and the missions are CC BY-NC-SA: do not commit them.
Seen in the user's gist "The Fries 2" (loud-only SWAT mission, about 992,000 characters, uncompressed format whose code starts `c%W`; my API fetch cut it at 921,600 so it could not be decoded here): spawners use `EnemyType = "Swat"` / `"SwatHeavy"` with `EnemyWeapons` listing weapons WITHOUT classes (`S97|F57|480 MCS|...`, `S97Shield`), plus `Aegis`, `Sawblade`, `LoudMusic`. So BreachCombatData must fall back to `EnemyType` for the class when a weapon entry has none (TODO before M9f). A 992 KB code will not fit the 181 KB importer path unchanged.
